# 安全边界

## 输入与身份

只接收 SDK 的真实群内 @ 事件；正文里写一个 @ 标签不会变成可信身份。应用、群、成员和事件
身份均来自 SDK，OpenID 是作用域标识，不是可逆的 QQ 号码。适配器检查事件新鲜度和北京时间
日期，拒绝私聊、引用和附件进入业务路径。两侧白名单取交集，配置失败默认关闭。

**公开站内 ID 不等于账号归属证明。** 真正接入业务账户时，由后端提供认证绑定或经审核迁移流程。
此仓库不宣称自动验证旧 QQ 本人身份，也不假定跨群 OpenID 可以互换。

## 聊天

只调用一次文本流，`tools: []`；没有 Agent 循环、文件、shell 或网络浏览执行器。平台身份和账本
不交给模型。输出限制长度与时限，拒绝工具调用、控制标签、可疑外链及伪称资金已到账的回复。
外链仅允许 `DAFEIYU_WEBSITE_ORIGIN` 的精确 HTTPS 源。提示词和输出过滤是辅助，核心边界是代码
没有给模型执行这些能力。不要将模型“不披露配置”的约束理解成可以将秘密放进提示词。

## 资金与发送

进程内去重与冷却不能替代持久化幂等。后端必须在事务中维护事件唯一键、活动/账号唯一键、身份
关联、预算、奖励和审计。多个实例、重启、旧码迁移与人工补发，都要由后端解决。
提示缺 ID 且发送确认后，同一人同一动作有一次立即补填机会，不放松奖励去重。
发送或执行结果未知不自动重试、不回放过期请求。冷却、队列满或撤销白名单仍可能抑制回复。

## 运行与范围

`prepare-source.mjs` 会把受限入口放在宿主的公开消息处理前，普通消息不会进入宿主 Agent。
管理员自己的 DSH 运行时仍是有权限的软件，不要将其管理端暴露公网。插件安装前审查上游版本，
用普通用户、私有配置目录和独立服务账户运行。systemd 文件仅为须自行验证的加固样例。

`slot-bridge.mjs` 仅绑定回环，限定路由、大小、时限、并发与回环槽位，转发凭据由后端验证；
它不是完整鉴权服务器，也不适合作为公网反向代理。

本仓库离线测试验证适配器及合成 SDK 事件，不能替代腾讯应用审核、权限、限额或真实群端到端验收。
本仓库没有提供完整生产控制台、持久化余额账本、历史数据迁移或生产自动部署。

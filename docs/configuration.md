# 配置参考

| 环境变量 | 用途 |
| --- | --- |
| `DAFEIYU_DSH_POLICY_FILE` | 仓库外预览 JSON 策略；不提供资金执行器 |
| `DAFEIYU_HUB_URL` | 自建能力后端，HTTPS 或 HTTP 回环 |
| `DAFEIYU_HUB_TOKEN_FILE` | 仓库外独立桥接令牌文件，与 URL 成对配置 |
| `DAFEIYU_WEBSITE_ORIGIN` | 允许推荐的精确 HTTPS 网站源，默认 `https://example.com` |
| `DAFEIYU_OFFICIAL_JOIN_EVENTS` | `1` 才订阅申请事件；仍须权限及后端开关 |
| `DAFEIYU_ENROLLMENT_DIAGNOSTICS` | `1` 开启只含阶段及布尔值的临时配对诊断 |
| `DAFEIYU_UPSTREAM_FILE` | 可选回环桥接读取的槽位片段文件 |

配置由宿主进程环境提供；`.env` 不自动加载。网站源不接受路径、端口、用户信息、查询串或片段。
帮助和固定回复可由后端策略下发，但聊天推荐链接仍只允许这个精确源。替换社区名和机器人昵称时，
同时修改 `src/replies.ts` / `src/text-chat.ts` 的默认公开文案并运行检查。

时间采用**北京时间 UTC+8**：静默起止值为当天分钟数，例如150为02:30、420为07:00；相同端点表示
全天静默。07:00–12:00早间，12:00–18:00午后，其余晚间。示例的金额、人数、身份和时间都是合成值。

业务策略含独立的活动/签到/余额/帮助开关，以及回复间隔、群间隔、个人冷却、有界队列和双白名单。
线上编辑器、奖励区间、概率、活动预算与暂停管理应由业务后端实现；公开适配器只消费策略。
